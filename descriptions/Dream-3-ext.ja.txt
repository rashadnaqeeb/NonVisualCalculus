zone.tetrapods.title = テトラポッドの岸
zone.tetrapods.body = 運河の水門の大きなコンクリート壁の下の水際の、枯れ草と雪の一画。コンクリートのテトラポッドが氷に向かって積まれ、裸の木が岩の上に傾いている。
zone.winchplatform.title = ウインチ塔の下の台
zone.winchplatform.body = 支柱に載った錆びたウインチ塔の下の水際のコンクリートの板。鉄の階段が板から上り、岩の上に崩れた木のはしごが横たわり、水面に油の虹色の膜、岸にテトラポッドが積まれている。
zone.slipway.title = 船台
zone.slipway.body = 崖のバンカーの暗い戸口から水へ下る長いコンクリートの斜路。真ん中に錆びたレールが2本走り、側面はひび割れて緑に染まり、足元にテトラポッドと浮氷が積まれている。
zone.cliffbeach.title = 崖の下の浜
zone.cliffbeach.body = 小島の岩の崖の足元の雪と枯れ草の帯。ウインチ塔の階段の下で、水際に岩と壊れた錨の鎖があり、浮氷が沿って座礁している。
zone.deadtree.title = 枯れ木
zone.deadtree.body = ねじれた枝の黒い裸の木の周りの枯れ草の一画。船台のコンクリート壁と岩の崩れの間にあり、向こうの岸にテトラポッドが並ぶ。
zone.isletice.title = 小島の氷の舌
zone.isletice.body = 小島のテトラポッドから外洋へ伸びる長い岸氷の舌。表面は凍った雪解け水で波打ち、先端から浮氷が漂い出している。
zone.winchstair.title = ウインチ塔の階段
zone.winchstair.body = 水際のコンクリートの板からウインチ塔のデッキへ上る、開いた手すりの錆びた鉄の階段。枯れた葦と岩の上にある。
zone.isletmeadow.title = 小島の草地
zone.isletmeadow.body = 海の要塞の小島の、枯れ草と砂の広い棚。船台のコンクリート壁と岸の間にあり、上に黒い枯れ木、草の中に岩、縁に沿って氷を守るコンクリートのテトラポッドの列がある。
zone.winchdeck.title = ウインチ塔のデッキ
zone.winchdeck.body = 水の上に支柱で立つ錆びたウインチ塔の手すり付きのデッキ。危険標識の付いた小さな小屋、下の板から鉄の階段が上ってくる踊り場があり、板の階段がバンカーへ向かう崖の道へ上っている。
zone.fortressdoor.title = 要塞のドア
zone.fortressdoor.body = 小島の崖の上の枯れ草の棚。砕けたコンクリートのブロックハウスの口を開けた戸口の外にあり、壊れた壁に木のはしごが立てかけられ、瓦礫から白樺の若木が生えている。
zone.fortresspath.title = 小島を上る道
zone.fortresspath.body = 灰色の岩の間を小島の草地からブロックハウスへ上る砂の道。暗い戸口の小さなコンクリートの小屋を過ぎ、裸の白樺の群れの下を通る。
zone.chainshore.title = 鎖の岸
zone.chainshore.body = 船台と灰色の岩の崖の間の水際の枯れ草と雪の窪み。上の廃墟のウインチから錆びた錨の鎖が氷の中へ垂れている。
zone.chainice.title = 鎖の氷
zone.chainice.body = 廃墟のウインチ小屋の下の岸氷の棚。錆びた鎖が横切って水の中へ伸び、縁に岩と枯れた葦が並び、向こうに浮氷が漂う。
zone.ruinstair.title = 廃墟の階段
zone.ruinstair.body = 灰色の岩の間を壊れたブロックハウスのドアのない開口部へ上るコンクリートの段。隣の板に錆びたウインチとケーブルの巻きがある。
zone.birchgap.title = 白樺の隙間
zone.birchgap.body = ひび割れたコンクリートの塔と裸の白樺の群れの間の狭い隙間。塔の側面から壊れた木のはしごが垂れ、道は船台へ続いている。
zone.fortresshole.title = 要塞の穴
zone.fortresshole.body = 海の要塞の主ブロックハウスの壊れた壁に接した草の切れ込み。錆びたパイプと丸いハッチの付いた倒れたコンクリートのトーチカの隣で、石積みの穴が廃墟の中へ開いている。
zone.bunkerpath.title = トーチカを過ぎる道
zone.bunkerpath.body = 錆びたパイプの付いた倒れたトーチカと、捨てられたタイヤのある茶色い湿地の水たまりの間の、砂と雪の踏み固めた道。ひび割れたコンクリート壁を過ぎて小島の頂上へ上っている。
zone.ruincorner.title = 廃墟の角
zone.ruincorner.body = ブロックハウスのひび割れた壁と裸の白樺の茂みの間の枯れ草と雪の帯。枯れ木が上に傾き、向こうに湿地がある。
zone.islettop.title = 小島の頂上
zone.islettop.body = 小島の頂の淡い色の砂と雪の広い棚。枯れ草の中に低い松と緑の茂み、足元に茶色い湿地の水たまり、縁に沿ってコンクリートの廃墟がある。
zone.desertercamp.title = 小島の野営地
zone.desertercamp.body = 小島の向こう側の枯れた葦と雪の空き地。黒ずんだ灰の焚き火の跡が枯れ木と低い岩の隣にあり、葦の向こうに湿地の水たまりと外海がある。
zone.loosefloe.title = 離れた浮氷
zone.loosefloe.body = 小島の岸のテトラポッドの間に座礁した一枚の氷。三方が開けた水になっている。

zone.slipwaytop.title = 船台の上端
zone.slipwaytop.body = コンクリートの船台の上端。2本の錆びたレールが崖のバンカーの暗い戸口へ上り、乾いた草と積まれた岩の間にある。

zone.pillboxledge.body = 船台の上端の隣の岩と枯れ草の棚。コンクリートのトーチカの暗い戸口の下にあり、縁に沿って岩と裸のねじれた木がある。
zone.chainfloe.title = 鎖の浮氷
zone.chainfloe.body = 錆びた錨の鎖が水へ下りてくる小島の岸に座礁した氷の板。テトラポッドと岩の間にある。
