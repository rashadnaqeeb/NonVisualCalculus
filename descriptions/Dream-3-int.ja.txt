# 非視覚計算の情景描写、日本語。文体は常体（普通形）で、ゲームのツールチップや調査文に合わせる。地名と人名はゲームの日本語表記に従う。
zone.gunhall.title = 砲室
zone.gunhall.body = 要塞の下のコンクリートのホール。床はひび割れた石板。埃よけの布を掛けた錆びた機械が短い鉄の階段のそばの壁際に立ち、床に丸いハッチがはめ込まれ、壁の1つは崩れ落ちて瓦礫と砂の斜面になり、そこに船台へのドアが開いている。
zone.eastdoor.title = 上の入口
zone.eastdoor.body = 要塞の上の出入口の内側の短い通路。手すり付きの旋回台のそばで砲室の上の階へ開いている。
zone.turntable.title = 旋回台
zone.turntable.body = コンクリートにはめ込まれた円形の鉄の軌道。周りに手すりがあり、中央の台座に砲塔の錆びた架台と歯車が載り、屋根からケーブルが垂れている。
zone.upperdeck.title = 上の回廊
zone.upperdeck.body = 旋回台の上の、錆の筋の走るコンクリートの手すり付きのデッキ。隣に砲架の歯車がそびえ、鋼の枠に緑の発電機が立って黄色いケーブルが床を這い、段がスリット窓の部屋へ上っている。
zone.entrycorridor.title = 入口の廊下
zone.entrycorridor.body = 正面のドアの内側のコンクリートの廊下。壁際に灰色のロッカー、床に木箱、壁に取り付けた歯車があり、階段が上の部屋へ上っている。
zone.upperstair.title = 上の階段
zone.upperstair.body = 手すり付きの鉄の階段。入口の廊下から上のスリット窓の部屋へ、コンクリートの壁に描かれた色あせた肖像画を過ぎて上っている。
zone.desertersroom.title = スリット窓の部屋
zone.desertersroom.body = 長いスリット窓の下の湾曲したコンクリートの部屋。壁に灰色のシーツが掛かり、奥の壁際にぼろ布と毛布の寝床、缶とボウルのテーブル、本の山がある。車輪付きの台に載った長い光学機器が窓辺に立ち、半分布で覆われ、本を積んだ椅子の隣にある。
zone.holepassage.title = 穴の通路
zone.holepassage.body = 要塞の壁のぎざぎざの穴から続く、壊れたコンクリート板の通路。床に瓦礫とボウルがあり、錆びた鉄の棒が隙間に渡してある。
object.exiteast = コンクリート壁の、重い蝶番ブロックの付いた錆びた鋼のドア。紫に照らされている。
object.exithole = 錆びた鉄の棒で支えた通路の岩壁のぎざぎざの穴。岩が積まれ、オレンジとピンクの光が流れ込んでいる。
object.exitmain = 錆びたコンクリート壁の戸口。オレンジとピンクの光が流れ込んでいる。
object.kim = 白いシャツと黒っぽいズボンの上にオレンジのボンバージャケットを着た細身の男。黒っぽい髪を後ろに撫でつけ、丸眼鏡をかけ、片手に小さな手帳を開き、もう片手にペンを持っている。
